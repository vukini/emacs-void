#+TITLE: Emacs Configuration

* About this file

=~/.emacs.d/init.el= loads this file with =org-babel-load-file=, which tangles
every =elisp= source block below into =config.el= (in order) and loads the
result. =config.el= is generated output — never edit it by hand; edit this file
instead.

Re-tangling happens automatically when this file is newer than =config.el=.
To force it: =M-x org-babel-load-file= on this file.

Blocks marked =:tangle no= are *not* tangled. They live in [[*Attic (disabled)][Attic (disabled)]] at the
end of the file.

The file is organised in load order:

| Section    | Contents                                        |
|------------+-------------------------------------------------|
| Bootstrap  | load-path, package archives, use-package        |
| Core       | custom file, backups, appearance, global keys   |
| Completion | vertico, corfu and the rest of the stack        |
| Navigation | avy, projectile, speedbar                       |
| Editing    | paredit, yasnippet, input methods               |
| Languages  | eglot plus per-language setup                   |
| Tools      | magit, pdf-tools, nov, gptel                    |
| Attic      | disabled config, kept for reference             |

** Package archives and use-package

=use-package-always-ensure= means a plain =use-package= declaration installs the
package if it is missing. Built-in packages therefore need an explicit
=:ensure nil=, which is used throughout this file.

#+BEGIN_SRC elisp
  (require 'package) ; use C-h P to describe packages

  (setq package-archives
        '(("gnu"       . "https://elpa.gnu.org/packages/")
          ("nongnu"    . "https://elpa.nongnu.org/nongnu/")
          ("melpa"     . "https://melpa.org/packages/")
          ("elpa-devel". "https://elpa.gnu.org/devel/")
          ("org"       . "https://orgmode.org/elpa/")))

  (package-initialize)
  (setq use-package-always-ensure t)

  (unless package-archive-contents
    (package-refresh-contents))
#+END_SRC

** Uniquify

https://elpa.gnu.org/packages/uniquify-files.html

=uniquify= is the built-in mechanism for making buffer names distinct when
several buffers visit files with the same name. With two different =init.lua=
files open from different directories, uniquify adjusts the buffer names so you
can tell them apart at a glance.

Source lives in =/usr/local/share/emacs/31.0.50/lisp/=; try =M-x find-library=
to read it.

#+BEGIN_SRC elisp
  (require 'uniquify)
#+END_SRC

** Haskell unicode input method

https://github.com/roelvandijk/emacs-haskell-unicode-input-method

Clone this repo into =~/.emacs.d/local=. (Still to work out how to add it as a
submodule.)

Type =->= and it is immediately replaced with =→=. Use =C-\= to toggle the input
method; =M-x describe-input-method haskell-unicode= shows the full table. An
ambiguous sequence like =<== can mean either =⇐= or =≤= — typing it offers a
choice, so press 1 or 2, or keep typing to accept the default.

To enable manually: =M-x set-input-method= or =C-x RET C-\= with
=haskell-unicode=.

#+BEGIN_SRC elisp
  (add-to-list 'load-path "~/.emacs.d/local/emacs-haskell-unicode-input-method")
  (require 'haskell-unicode-input-method)

  (add-hook 'haskell-mode-hook
            (lambda () (set-input-method "haskell-unicode")))
#+END_SRC

** gptel

Keys are pulled from the login shell via =exec-path-from-shell= (loaded in
[[*Shell environment][Shell environment]]) and re-exported into the Emacs environment, so the =:key=
lambdas can read them lazily.

#+BEGIN_SRC elisp
  (use-package gptel
    :ensure t
    :config
    (setenv "OPENAI_API_KEY"
            (or (getenv "OPENAI_API_KEY")
                (exec-path-from-shell-getenv "OPENAI_API_KEY")))
    (setenv "PERPLEXITY_API_KEY"
            (or (getenv "PERPLEXITY_API_KEY")
                (exec-path-from-shell-getenv "PERPLEXITY_API_KEY")))

    (setq my-gptel-openai
          (gptel-make-openai "OpenAI"
            :key (lambda () (getenv "OPENAI_API_KEY"))
            :models '(gpt-4o gpt-4o-mini)))

    (setq my-gptel-perplexity
          (gptel-make-perplexity "Perplexity"
            :key (lambda () (getenv "PERPLEXITY_API_KEY"))
            :models '(sonar sonar-pro)))

    ;; Default backend
    (setq gptel-backend my-gptel-perplexity
          gptel-model 'sonar-pro))
#+END_SRC
